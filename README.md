# 🛠️ Quick Start (Real-World Usage)

## 1. Initial Setup

Ensure Python 3.10+ is installed.

### Install dependencies

```bash
pip install -r requirements.txt
```

---

## 2. Configure Dataset

Place your dataset inside the `data/` folder.

Example:

```bash
data/sales_data.csv
```

---

## 3. Run Visualization Engine

```bash
python main.py
```

This will:

- Load dataset
- Process numerical data
- Generate charts automatically
- Save visual reports

---

## 4. Generate Specific Graphs

### Line Chart

```bash
python scripts/line_chart.py
```

### Bar Graph

```bash
python scripts/bar_graph.py
```

### Pie Chart

```bash
python scripts/pie_chart.py
```
